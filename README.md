## 📌 Projeto em Destaque: API REST de Gestão de Projetos (CRUD)

Uma API RESTful desenvolvida para gerenciamento de projetos de software, com operações completas de CRUD e persistência de dados em banco relacional.

### 🌟 Funcionalidades
- **`GET /projetos`**: Lista todos os projetos cadastrados na base de dados.
- **`POST /projetos`**: Cadastra um novo projeto com validação de dados.
- **`PUT /projetos/{id}`**: Atualiza os dados de um projeto existente por ID.
- **`DELETE /projetos/{id}`**: Remove um projeto da base de dados por ID.
- **Documentação Automática**: Swagger UI gerado automaticamente no endpoint `/docs`.
